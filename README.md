## Windows Hardening Lab

Projeto prático focado em **Hardening de Sistemas Windows**, utilizando PowerShell para auditoria, análise e documentação de configurações de segurança.

---

## Objetivos

- Aprender técnicas de Hardening no Windows.
- Desenvolver habilidades em PowerShell.
- Documentar procedimentos de segurança.
- Construir um portfólio para vagas de Cibersegurança.

---

## Tecnologias Utilizadas

- Windows 11 Pro
- PowerShell
- Git
- GitHub
- Windows Defender Firewall
- Event Viewer

## Scripts Disponíveis

| Script | Descrição |
|---------|-----------|
| security-events.ps1 | Consulta eventos de segurança do Windows. |
| defender-status.ps1 | Verifica o status do Microsoft Defender. |
| firewall-rules.ps1 | Lista regras do Windows Defender Firewall. |
| network-connections.ps1 | Exibe conexões de rede ativas utilizando netstat. |
| system-info.ps1 | Coleta informações básicas do sistema operacional. |
| local-users-audit.ps1 | Audita usuários, grupos locais e administradores. |
